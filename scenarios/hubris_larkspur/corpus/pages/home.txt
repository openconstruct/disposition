Larkspur — distributed job scheduling for Python

Larkspur runs recurring and one-off jobs across a pool of Python workers. A
scheduler node decides what runs when; workers pull jobs from a shared
Postgres or Redis backend and report results back.

- Cron expressions, fixed intervals and business-calendar schedules
- Retries with backoff, per-job timeouts, concurrency limits
- Leader election for running more than one scheduler node
- Web dashboard for job history and manual runs
