Security policy

Please report vulnerabilities privately to security@larkspur-sched.org.
We acknowledge reports within 72 hours and aim to ship a fix for confirmed
issues within 30 days.

Supported versions: the latest minor release (currently 2.6.x) receives
security fixes. 2.5.x receives security fixes until 31 December 2026.

Independent review: Larkspur 2.5 was reviewed by Harbin & Voss Security in
March 2026. All findings were fixed in 2.5.2; the summary report is linked
from this page. Fennick Labs holds a SOC 2 Type II report covering its
support operations, available to customers under NDA.

Past advisories:
- LSA-2025-01: dashboard did not require authentication for the manual-run
  endpoint when behind certain reverse proxies. Fixed in 2.4.3.
- LSA-2026-01: job arguments were logged in plain text at DEBUG level.
  Fixed in 2.5.2.
